# Changelog

All notable changes to Angular Boilerplate will be documented in this file.

The boilerplate version always matches the version of `@angular/core` it is based on.

For example:

- Angular Boilerplate `22.1.0` → `@angular/core` `22.1.0`
- Angular Boilerplate `22.2.0` → `@angular/core` `22.2.0`

This convention makes it immediately clear which Angular version a release targets.

## [22.1.0] - 2026-08-21

> Based on Angular `22.1.0`.

### Added

- Signal-based application architecture.
- Server-side rendering and hydration.
- Incremental hydration and `@defer` examples.
- Angular Resource APIs.
- Signal Forms examples.
- Modern dependency injection with `@Service()`.
- Functional HTTP interceptors.
- Authentication state and route guard.
- Centralized API error handling.
- Italian and English internationalization.
- SEO metadata management.
- Tailwind CSS 4.
- Accessibility foundations.
- Vitest test suite.
- ESLint and Prettier configuration.
- StackBlitz live demo.
- Interactive Angular feature showcase.

### Documentation

- Angular feature documentation integrated into the application.
- Architecture documentation.
- Project setup and development documentation.
- StackBlitz usage instructions.

### Infrastructure

- SSR and SSG configuration.
- Automated formatting and linting.
- Unit testing infrastructure.
