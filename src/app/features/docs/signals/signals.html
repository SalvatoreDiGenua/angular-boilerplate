Signal-first Angular

State becomes explicit, local and reactive.

Angular's signal APIs are now the preferred foundation for new stateful code. The boilerplate keeps the mental model small: writable signals hold state, computed values derive it, linkedSignal preserves writable relationships, and resources connect asynchronous work to that same reactive graph.

A modern state flow

From model to async data. 

          
readonly userId = signal('42');
readonly user = httpResource(() => '/api/users/' + this.userId());

readonly displayName = computed(() =>
  this.user.value()?.name ?? 'Loading…'
);

readonly formModel = signal({
  displayName: '',
  email: '',
});

readonly form = form(this.formModel, (path) => {
  required(path.displayName);
  email(path.email);
});

Signal Forms are part of @angular/forms/signals ; the boilerplate documents the pattern but deliberately does not force every application to use it when an existing Reactive Forms model is a better fit.
